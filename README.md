# Schweiß-Assistent

Installierbare, offline nutzbare Web-App (PWA) mit Einstellwerten für den WELDINGER MWPE 209 HF/AC pro Combi PFC und den Automatik-Schweißhelm AH-800. Die Werte stammen aus den Herstellerhandbüchern, sonst sind es gekennzeichnete Richtwerte.

React, TypeScript, Material UI, Vite. Kein Backend.

## Schnellstart

```
npm install
npm run dev     # Entwicklung
npm test        # Tests
```
